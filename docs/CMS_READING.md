# 阅读库分类、正文预览与播放

阅读库只展示本人当前固定发布版本。桌面侧栏按分类浏览，手机点分类按钮展开列表；“全部文章”和“未分类”均有发布文章数量。选分类后从第一页开始，上一/下一页可以访问该分类下的全部文章。进入全文后返回，会保留分类和页码。

每篇卡片显示标题、发布正文前三个视觉行和音频入口。正文使用CSS三行截断，保留原文换行，短文不补空白；预览与全文都来自已发布正文，不使用草稿或摘要冒充正文。

有固定音频的文章可以直接在卡片点播放，支持暂停、进度、停止和下载；未附音频会明确显示状态。只在点击后载入该发布音频，切换文章会停止前一段，切换分类/分页或离开阅读页会清理。加载失败可重试，失效发布需刷新，不自动生成TTS。

## 分类与历史语义

既有发布快照只冻结末级分类id、名称、slug和版本，没有保存当时的父级链。因此阅读导航按已发布快照平铺，统计直接归属；不会把编辑侧现在的分类树套到旧文章，也不包含子分类文章。

分类后来改名、调整父级或删除，旧发布的文章、分类名称、正文和音频仍保持原快照并可通过阅读分类访问。同一个分类id的当前发布文章可能具有不同冻结名称；导航按id合并数量，取最新可见发布的名称并显示其他发布名称，卡片继续显示其自身名称。

没有当前发布文章的管理分类不列入阅读导航，草稿和草稿分类名称不会暴露给只读接口。未分类使用发布快照的null归属；空或已不存在的分类筛选有空态，可重置到全部。分类数量仅统计当前可读发布，与列表使用同一数据库快照。

## 接口与资源

API1.4.0：GET /v1/cms/read/articles的分页响应新增navigation（categories、uncategorizedCount、totalArticles），其统计遵循同样的权限、q和tag，忽略当前category/offset；category接受精确分类UUID或uncategorized。GET /v1/cms/read/categories返回当前授权发布范围的无搜索分类导航。旧release JSON不回填，不新增数据库迁移。

现有登录和已批准只读凭证的精确末级分类权限保持不变，不根据父子关系扩大读取。没有创建真实AI凭证或匿名开放私人文章。阅读音频请求保持同源会话与元数据校验，独立取消控制不会修改原工作台请求行为；401沿用既有会话失效和CSRF缓存清理。

前端只有一个活动audio、一个未完成媒体请求、至多一个对象URL。取消、切换与卸载会暂停并释放资源，迟到响应不会覆盖新选择。没有新增依赖或后台服务，未实测内存占用。
