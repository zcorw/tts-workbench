# 分类管理

分类由 CMS 管理，一篇文章属于一个分类，也可以保持“未分类”。原工作台继续管理日文正文与精细朗读设置；分类调整不需要重新生成音频。

## 管理分类

独立站点的“分类管理”显示父子树、每类直接文章数和直接子分类数。可新建、改名、选择父级和设置排序值。较小的排序值优先；同值按名称与标识稳定排序。不能把分类放到自己或后代下面；后端同样在事务中检查，防止并发操作形成循环。

点击分类名称可查看直属文章。“未分类”包括 CMS 未分类文章和从原工作台保存、尚未建立 CMS 元数据的文章。父分类计数不包含子分类文章，避免筛选和数量含义混淆。

有文章或子分类时禁止删除。先在文章列表移动文章，再修改子分类的父级，确认分类为空后删除。删除不会移除正文或音频，历史发布中的分类名称与归属保持原快照。

## 归类文章

单篇文章可在编辑页选择分类；列表可选中当前页的一篇或多篇后批量移动到目标分类或“未分类”。批量操作使用列表读取时的正文版本与 CMS 版本；任何一篇已改变，整批拒绝并保留选择，重新加载并核对后才能重试，不会静默覆盖。

分类移动只修改草稿 CMS 元数据和 CMS 版本。正文、正文版本、精细朗读设置、音频、音频过期状态以及已发布版本保持不变。分类树不会扩大已有只读凭证的可读范围；没有新增真实凭证或匿名文章权限。
