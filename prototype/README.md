# YOMI · 日文语音工作台交互原型

根据 2026-09-06 产品说明书 v0.7 制作的独立 HTML 原型。YOMI 是暂用名称；视觉方案和概念音色用于评审，不代表最终品牌或供应商选择。

## 打开

直接用现代浏览器打开 [index.html](index.html)。所有页面、样式及交互均在本地文件中，无需安装前端依赖或构建。

也可以从 `tts-workbench` 目录运行 `python -m http.server 4178 --bind 127.0.0.1`，访问 `http://127.0.0.1:4178/prototype/`。本地服务器方式可保持稳定的浏览器存储来源，并可打开完整需求文档链接。

## 体验流程

1. 工作台默认载入日文文章和“林”的演示账户，已有「京都」「鴨川」两条规则。
2. 点击“生成语音演示”，展开“检查本次提交的读法文本”。有本地日文系统音色时可点击播放试听。
3. 在正文拖选「日本橋」，点击“修改读法”，输入 `にほんばし`，保存个人规则。也可点击“试选「日本橋」”，或用键盘选区后操作浮动按钮。
4. 原文仍显示汉字，所有同词命中出现标记；已生成结果提示需要重新生成。
5. 点击“新文章”，载入另一篇文章，验证已保存规则继续应用。
6. 到“个人读法规则”搜索、添加、编辑、试听或删除。删除前会明确说明当前及以后文章的影响范围。
7. “产品需求说明”包含 19 个功能要求及验收概述、工程边界、待选方案与非目标；底部可模拟下一次保存/删除失败、合成失败及登录过期。

演示账户“林”和“佐藤”使用独立的规则集合；也可创建演示账户。任意 8 位演示密码仅用于表单体验，不存储、不发送，也不进行真实凭据验证。正式产品是否开放公众注册尚未确定。

## 需求主线

- **日文优先**：MVP 必须包含真实日文音色、`ja-JP` 请求、日文读法及可听验收。原 Gateway 的 `zh-CN` 限制是待修复的技术缺口。
- **正文直接修音**：输入 → 生成听音 → 正文选词 → 修改读法 → 再生成；不要求先跳到规则页。
- **默认个人规则**：保存后影响当前同词与以后文章；原文与读法分离，保存失败不假装生效。
- **结果与提交一致**：正文、规则、音色或语速改变后，保留旧结果并提示重新生成；在途结果绑定提交时快照。
- **账户独立工程**：账户模块和 Gateway 分别独立维护，组合应用通过明确版本的公开包引入。账户工程候选名为 `nest-account`，不表示已经创建。

完整基线见 [产品说明书](../docs/PRODUCT_SPEC.md)、[架构规划](../docs/ARCHITECTURE.md) 和 [开发清单](../TODO.md)。本次仅新增交互原型，未将后台开发任务标记完成。

## 能力边界

| 能力 | 此原型 | 正式产品要求 |
|---|---|---|
| 正文编辑、选词、规则标记 | 可操作；原字不变，按字面最左最长单轮匹配 | 日文字符、输入法与浏览器兼容性完整验证 |
| 个人规则 CRUD | 写入浏览器 localStorage；保存/删除错误可模拟 | 服务端持久化、身份隔离、并发控制 |
| 版本冲突 | 多窗口顺序变更可检测并拒绝旧版本覆盖；本地存储无数据库事务保证 | 服务端原子条件写入，可靠处理并发 |
| 账户开通及登录 | 模拟界面；本地按账户区分，不是真实安全边界 | 独立账户模块验证凭据与会话 |
| 合成结果 | 生成规则应用文本及提交快照 | Gateway 返回真实日文 MP3 |
| 播放/暂停 | 仅尝试浏览器 `localService` 日文音色；无音色时明确提示 | 播放真实合成音频 |
| 下载 | 可导出 JSON 合成说明；MP3 按钮明确禁用 | 可下载 MP3，并正确释放旧音频资源 |
| 数据保留 | 规则本地持久化，正文与结果仅页面内存 | 服务端数据生命周期及日志政策落实 |

此原型没有后端请求，也不会调用付费合成。假名替代文本只是读法表现的演示；实际供应商能力、重音和最终效果仍需验证。浏览器本地存储清除后规则会消失；不适合作为真实词汇管理工具。

“仅此处”仍为后续可选项；首版不包含释义、查词、手动发布、自动错音识别、音文同步或 IPA 编辑。

## 验证

自动交互检查位于 [qa/check.cjs](qa/check.cjs)。需要 Node.js、Playwright 及 Chromium；在模块可解析的环境运行 `node prototype/qa/check.cjs`。默认测试地址为上面的本地服务器，支持 `BASE_URL` 环境变量覆盖。

检查覆盖正文实际选区、跨文章复用、失败保留、生成快照与过期提示、删除范围、窗口版本冲突、换行与 emoji、演示账户隔离、390px 窄屏交互和浏览器异常。检查结果及截图位于 `qa/artifacts/`。自动检查不能替代真实日文音频或生产安全验收。
