# YOMI 前端页面模板

独立、可运行的 HTML / CSS / 原生 ES Modules 前端。保留 `../../prototype` 作为设计对照，继承纸张色、深绿导航、橙色读法标记；产品界面不含需求说明、开发参数或异常模拟入口。

## 运行

从 `D:/Workspace/github/tts-workbench` 执行：

```powershell
python -m http.server 4180 --bind 127.0.0.1
```

打开 **http://127.0.0.1:4180/apps/web/**。无需安装运行依赖或构建。ES Modules 和 WebCrypto 需要 localhost / HTTPS，不支持双击 file://。首次使用点击“创建账户”，创建自己的本机账户后登录；不预置账户、不接受任意密码登录。

这次选择原生模块是可逆的模板实现选择，未冻结正式应用框架。未创建账户后端仓库，未修改 Gateway，未将项目 TODO 的后台任务勾选完成，未提交或部署。

## 本地能力与真实服务边界

**前端模板完成不等于正式产品服务已接通。**

- 账户是设备内的功能适配器，UI 明示“本机账户”。创建后使用 PBKDF2-SHA256 + 随机 salt 校验密码；不存明文密码、不发送密码。数据在 localStorage，会话在 sessionStorage，默认 8 小时。这只是本机体验，不是服务端身份安全边界；能控制浏览器存储的人仍能修改本机身份。生产必须换成独立账户模块支持的宿主 API。
- 自助注册在本地模板默认开启，方便首次创建本机账户。`registrationOpen: false` 可验证受控注册布局；这不是决定正式生产开放注册，原规划的默认关闭建议仍待部署决策。
- 规则按本机账户划分，写入成功后才更新 UI。支持存储错误、revision 冲突；支持 Web Locks 的浏览器串行化跨标签读改写。缺少 Web Locks 时只能做顺序 revision 校验，不承诺数据库级事务。
- 语音只枚举 `localService` 的日文系统音色，真实开始播放事件后才显示结果。没有音色时生成和试听不可用，不伪造音色、合成成功、进度或 MP3。
- 系统朗读没有可下载音频字节，下载按钮禁用并说明原因。适配器返回真实可播放媒体及 `downloadUrl` 后才可启用；不将 JSON 或占位文件伪装成音频。
- 当前机器的自动化浏览器无可用日文音色。因此尚未完成真实日文发音效果验收。测试用 PCM 正弦音频仅检查浏览器播放与结果状态，绝不作为日文语音或 Gateway 验收证据。
- 正文与音频结果仅在当前页面内存；刷新丢失未保存正文。正常退出清空正文和播放结果，会话失效保留正文供同账户重新登录；切换至其他账户清空旧正文。

## 后端接入

Web 只消费组合应用的 HTTP API；账户与 Gateway 的公共包由宿主后端组合，前端不引入兄弟仓库源码。

1. 替换 `accountService.current/login/register/update/logout`。返回最小账户资料及规则状态，服务器负责真实凭据、HttpOnly 会话、注册策略、CSRF、失效撤销及所有者授权；将 SESSION 错误归一为 `{code: 'SESSION', message}`。
2. 替换 `ruleService.mutate(intent, kind, word, reading)`，保留 expected revision / owner 操作约束。真实所有者必须来自会话，不能相信前端传入 owner。服务器成功后返回新规则集合与版本；失败抛错，禁止乐观假保存。正式字面匹配/规范化以双方确认契约为准。
3. 替换 `speechService.voices/start/stop/pause/resume`。目录仅列真实授权 ja-JP 音色。`start` 接收不可变提交快照，失败不覆盖上一个结果，不自动重试请求。HTTP 适配器应使用服务端可信个人规则编译，不能直接相信客户端别名字符串就是最终授权快照。
4. 真实音频适配器应以返回 Blob 创建 Audio，实际媒体可用后调用 `onStart({kind, downloadUrl})`；结束/失败触发对应回调。释放被替换及退出后的 Object URL，依据真实 MIME 设置下载扩展名。当前 `downloadButton` 按规划 MP3 命名，其他格式接入时须同步映射。
5. 接入后替换本机范围文案与数据生命周期标签。错误可携带 requestId；当前无服务端请求，不虚构请求编号。

原 Gateway 仍有日文配置、音色、规则快照等缺口。本交付没有验证或声称这些后端能力已实现。
